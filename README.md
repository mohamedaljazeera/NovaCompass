NovaCompass leverages a scalable, event-driven architecture to facilitate dynamic distributed processing-engine, utilizing auto-scaling capabilities to enhance predictive-analytics performance.

NovaCompass is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/NovaCompass.git`
2. `cd NovaCompass`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure NovaCompass, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
